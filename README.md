# NanoSharp-RTOS
A port of NanoSharp to microcontrollers (eg. ESP32). <br>
NOTE: gui.* and fs.open doesn't work. <br>
<h1>Installation</h1>
<hr>
1. Install TinyGo on your microcontroller with interpreter.go <br>
2. Install LittleFS on your microcontroller <br>
3. Save your NanoSharp script as script.ns <br>
If you did all correctly, your script will correctly run. <br>
